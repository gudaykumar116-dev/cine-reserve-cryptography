Secure Online Movie Ticket Booking System Using Cryptography

Demonstrating practical applications of cryptography inside a real-world booking system.

1. Password Security

Algorithm: BCrypt

Never store plain-text passwords. BCrypt is used to securely hash user passwords before storing them in the database.

Registration: Password → BCrypt Hash → Database Login: Password → BCrypt Verify ← Database

2. Booking Integrity

Algorithm: SHA-256

Detect modification of booking/ticket data. The hash ensures that the ticket data hasn't been altered.

Data = BookingID + Email + TotalAmount Hash = SHA-256(Data) View Ticket: Recalculate SHA-256(Data) == Stored Hash ? ✅ VERIFIED : ❌ FAILED

3. Data Confidentiality

Algorithm: AES-256-GCM

Protect selected sensitive data such as payment methods and addresses using symmetric encryption.

Sensitive Data (Payment Info) ↓ AES-256-GCM Encryption ↓ Database (Encrypted) ↓ Authorized Backend ↓ Decryption → Original Data

4. Ticket Authenticity

Algorithm: RSA Digital Signature

Verify ticket authenticity using Public/Private key pairs. The private key remains secure on the backend.

Booking Data ↓ Sign with RSA Private Key ↓ Digital Signature Stored View Ticket: Verify with RSA Public Key ✅ VALID : ❌ INVALID
